# 10. PostGIS 空间数据库

> 配套可运行脚本：`10. PostGIS 空间数据库.py`

## 0. 一句话结论

**PostGIS 是 PostgreSQL 的空间扩展，让你在数据库里做空间查询。作为 GIS 专业，这是你的核心优势——整个技术栈可以变成「Python → FastAPI → SQL → PostgreSQL → PostGIS → GeoAI/LLM」。**

---

## 1. 什么是 PostGIS

PostGIS = PostgreSQL 的空间扩展：

- 空间类型：点 `Point`、线 `LineString`、面 `Polygon`
- 空间函数：距离、相交、包含、缓冲区
- 空间索引：GiST 索引加速空间查询

普通数据库能查「`age > 18`」，PostGIS 能查「**离我 1000 米内的建筑**」。

---

## 2. ST_DWithin 空间查询

```sql
SELECT *
FROM buildings
WHERE ST_DWithin(
    geom,
    ST_SetSRID(ST_Point(112.9388, 28.2282), 4326),
    1000
);
```

解读：

| 函数 | 作用 |
|------|------|
| `ST_Point(经度, 纬度)` | 创建一个点 |
| `ST_SetSRID(..., 4326)` | 指定坐标系（4326 = WGS84 经纬度） |
| `ST_DWithin(geom, 点, 1000)` | 判断 geom 是否在点周围 1000 米内 |
