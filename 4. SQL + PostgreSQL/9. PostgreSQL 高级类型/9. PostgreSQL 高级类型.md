# 9. PostgreSQL 高级类型

> 配套可运行脚本：`9. PostgreSQL 高级类型.py`

## 0. 一句话结论

**PostgreSQL 除了数字和字符串，还有 JSONB（存查 JSON）、ARRAY（数组）、UUID（全局唯一标识）等强大类型，对 GIS / GeoAI 方向尤其有用。**

---

## 1. JSONB

```sql
CREATE TABLE tasks (
    metadata JSONB
);
```

存入：

```json
{
    "model": "Qwen",
    "temperature": 0.7,
    "task": "geospatial_reasoning"
}
```

直接在 PostgreSQL 中查询 JSON：

```sql
SELECT * FROM tasks WHERE metadata->>'model' = 'Qwen';
SELECT * FROM tasks WHERE metadata @> '{"task": "geospatial_reasoning"}';
```

| 操作符 | 作用 |
|--------|------|
| `->` | 取 JSON 字段（返回 JSON） |
| `->>` | 取 JSON 字段（返回文本） |
| `@>` | 判断是否包含某 JSON |

> 用途：存灵活元数据（模型参数、配置、任务描述），不用为每个字段建列。

---

## 2. ARRAY

```sql
CREATE TABLE items (
    tags TEXT[]
);

CREATE TABLE geo (
    embedding_ids INTEGER[]
);
```

```sql
INSERT INTO items (tags) VALUES (ARRAY['gis','ai','backend']);
SELECT * FROM items WHERE 'ai' = ANY(tags);
```

用途：标签、embedding 向量 id、坐标序列等。

---

## 3. UUID

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY
);
```

后端 API 常见 UUID 主键，因为：

- **分布式系统里全局唯一**，不依赖单库自增。
- **不暴露业务量**（自增 id 会泄露有多少用户/订单）。

Python 生成：

```python
import uuid
print(uuid.uuid4())
```

## 5. 小结

| 类型 | 用途 |
|------|------|
| JSONB | 存查 JSON 元数据 |
| ARRAY | 标签、向量 id |
| UUID | 全局唯一主键 |

**核心认知**：PostgreSQL 是「功能最强的开源关系库」，这些高级类型让你不必为每个需求都建一堆列——GIS/GeoAI 的元数据、标签、分布式 ID 都能优雅建模。
