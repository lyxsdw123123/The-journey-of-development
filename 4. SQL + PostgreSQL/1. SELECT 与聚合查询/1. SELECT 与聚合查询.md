# 1. SELECT 与聚合查询

> 配套可运行脚本：`1. SELECT 与聚合查询.py`（用 Python 内置 sqlite3 真实执行）

## 0. 一句话结论

**SQL 查询有固定执行顺序 `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`。理解这个顺序，比死记语法更重要。**

---

## 1. SELECT 基础

```sql
SELECT *
FROM users
WHERE age > 18;
```

然后进阶：

```sql
SELECT name, age
FROM users
WHERE age > 18
ORDER BY age DESC
LIMIT 10;
```

需要理解的关键字：

| 关键字 | 作用 |
|--------|------|
| `SELECT` | 选哪些列 |
| `FROM` | 从哪张表 |
| `WHERE` | 过滤行 |
| `ORDER BY` | 排序 |
| `LIMIT` | 取前 N 条 |
| `OFFSET` | 跳过前 N 条（分页） |
| `DISTINCT` | 去重 |

---

## 2. 聚合查询

后端非常常见：

```sql
SELECT department, COUNT(*)
FROM users
GROUP BY department;
```

聚合函数：

| 函数 | 含义 |
|------|------|
| `COUNT` | 计数 |
| `SUM` | 求和 |
| `AVG` | 平均 |
| `MAX` | 最大 |
| `MIN` | 最小 |

配合 `GROUP BY`（分组）和 `HAVING`（过滤组）：

```sql
SELECT user_id, COUNT(*) AS order_count
FROM orders
GROUP BY user_id
HAVING COUNT(*) > 10;
```

---

## 3. 执行顺序（重点）

```text
FROM       先确定数据来源
   ↓
WHERE      分组前，过滤「行」
   ↓
GROUP BY   分组
   ↓
HAVING     分组后，过滤「组」
   ↓
SELECT     选列、算聚合
   ↓
ORDER BY   排序
   ↓
LIMIT      取前 N 条
```

**关键区分**：

- `WHERE`：分组**前**过滤行，不能写聚合条件。
- `HAVING`：分组**后**过滤组，可以写 `COUNT(*) > 10`。

```sql
-- 错误：WHERE 里不能用聚合函数
SELECT department FROM users WHERE COUNT(*) > 1;  -- 报错

-- 正确：用 HAVING
SELECT department, COUNT(*) FROM users GROUP BY department HAVING COUNT(*) > 1;
```

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| SELECT 结构 | 选列 → 过滤 → 排序 → 分页 |
| 聚合函数 | COUNT/SUM/AVG/MAX/MIN |
| GROUP BY | 按某列分组 |
| HAVING | 分组后过滤 |
| 执行顺序 | WHERE 先于 GROUP BY 先于 HAVING |

**核心认知**：SQL 是「声明式」语言——你描述「要什么」，数据库决定「怎么取」。理解执行顺序，才能写出正确且高效的查询。
