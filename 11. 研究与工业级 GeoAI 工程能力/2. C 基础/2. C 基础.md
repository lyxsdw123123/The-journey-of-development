# 2. C 基础

## 0. 一句话结论

**你不需要学完整的 C/C++ 工程开发，而是理解 Python 和 AI 框架下面发生了什么——变量、指针、内存、编译，这样看到 PyTorch/CUDA/NumPy/GDAL/PostGIS 底层就不会陌生。**

---

## 1. 底层链路

```text
Python 对象
    ↓
内存
    ↓
C/C++
    ↓
操作系统
    ↓
CPU / GPU
```

---

## 2. 指针：理解「地址」

```c
int x = 10;
int *p = &x;   // p 存的是 x 的内存地址
```

```text
x（变量）
 ↓ 存放于
内存地址（如 0x7fff...）
 ↑
p（指针，存这个地址）
```

**指针 = 存「内存地址」的变量。** 理解了指针，就理解了「Python 变量为什么是引用」。

---

## 3. 核心概念

| 概念 | 一句话 |
|------|--------|
| 变量 | 一块有名字的内存 |
| 指针 | 存地址的变量 |
| 数组 | 连续的内存块 |
| 结构体 | 组合多个字段 |
| 栈 | 函数局部变量（自动分配释放） |
| 堆 | 手动分配的内存（malloc/free） |

---

## 4. 编译流程

```text
gcc
  ↓ 预处理（展开 #include、宏）
  ↓ 编译（C → 汇编）
  ↓ 汇编（汇编 → 机器码）
  ↓ 链接（合并库，生成可执行文件）
可执行文件
```

```bash
gcc demo.c -o demo   # 编译
./demo               # 运行
```

---

## 5. 为什么学 C 基础

以后看到这些，就不会完全陌生：

```text
PyTorch → C++ / CUDA
NumPy   → C
GDAL    → C/C++
PostGIS → C
```

AI 框架的「性能关键路径」几乎都是 C/C++/CUDA 写的。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| 指针 | 存地址的变量 |
| 内存 | 栈/堆 |
| 编译 | 预处理→编译→汇编→链接 |
| 意义 | 理解 AI 框架底层 |

**核心认知**：C 基础不是让你写 C，而是让你「看懂底层」——Python 的引用、内存管理、AI 框架的性能，根源都在 C/C++/CUDA。懂一点 C，这些就不再是黑盒。
