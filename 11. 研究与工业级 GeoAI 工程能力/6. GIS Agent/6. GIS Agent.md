# 6. GIS Agent

## 0. 一句话结论

**第二个项目才是重点——「让用户用自然语言指挥 GIS」。Agent 接收中文空间问题，规划任务、调用 GIS 工具、做空间分析、查库、生成地图并解释结果。**

---

## 1. 工作流程

用户：

> 「分析长沙市高校周边 3 公里范围内的商业设施，统计各高校附近商业设施数量，最后生成一张地图。」

Agent 流程：

```text
用户请求
   ↓
LLM（任务规划）
   ↓
调用 GIS 工具
   ↓
空间分析（buffer / intersect）
   ↓
数据库查询（PostGIS）
   ↓
地图生成
   ↓
结果解释
```

---

## 2. GIS 工具集

```text
GIS Agent Tools
│
├── spatial_query        空间查询
├── buffer               缓冲区
├── intersect            相交
├── clip                 裁剪
├── spatial_join         空间连接
├── calculate_distance   距离计算
├── raster_analysis      栅格分析
├── geocoding            地理编码
├── map_generation       地图生成
└── postgis_query        PostGIS 查询
```

---

## 4. 关键思想

| 分工 | 谁 |
|------|-----|
| 决策（理解意图、规划） | LLM |
| 计算（空间分析、查询） | PostGIS + GIS 工具 |

**LLM 负责「想」，GIS 负责「算」。** 这正是前面 Agent + Tool Calling 思想的落地。

---

## 5. 动手清单

1. 先实现 3 个工具：`buffer`、`intersect`、`spatial_query`。

2. 让 LLM 能根据用户问题，自动选工具、传参数。

3. 最后加 `map_generation`，把结果渲染成地图（GeoJSON + 前端）。

---

## 6. 小结

| 概念 | 一句话 |
|------|--------|
| GIS Agent | 自然语言指挥 GIS |
| 工具集 | buffer/intersect/spatial_query/… |
| 分工 | LLM 决策，GIS 计算 |

**核心认知**：GIS Agent 是这条技术链的「集大成者」——它把 LLM（决策）、PostGIS（空间计算）、GIS 工具（分析）、地图（可视化）串成一个能听懂人话的空间分析系统。这是你区别于普通后端和普通 LLM 工程师的核心能力。
