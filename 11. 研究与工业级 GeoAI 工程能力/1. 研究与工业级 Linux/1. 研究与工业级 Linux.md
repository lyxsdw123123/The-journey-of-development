# 1. 研究与工业级 Linux

## 0. 一句话结论

**这一阶段的 Linux 是「研究/工业级」——比上一阶段「后端工程 Linux」更深：理解系统/进程/内存/CPU/GPU、会看 journalctl、懂网络与反向代理，最终能诊断并优化 GeoAI 服务。**

---

## 1. 与上一阶段「后端工程 Linux」的区别

| | 后端工程 Linux（第 9 主题） | 研究/工业级 Linux（本主题） |
|--|--------------------------|---------------------------|
| 目标 | 能部署、维护项目 | 能诊断、优化 GeoAI 服务 |
| 重点 | 基本命令、SSH、systemctl、日志 | 系统/进程/内存/CPU/GPU、网络、性能 |
| 命令 | ls/cd/cp/tail/grep | ps/top/htop/df/du/free/curl/journalctl |

一句话：**上一阶段是「会用」，这一阶段是「会看会诊断」。**

---

## 2. 系统与资源

```bash
top / htop          # CPU/内存/进程/负载
free -h             # 内存
df -h               # 磁盘
du -sh dir          # 目录大小
nvidia-smi          # GPU 显存/利用率（GeoAI 必备）
```

---

## 3. 进程与权限

```bash
ps aux              # 所有进程
kill <PID>          # 结束进程
chmod 755 file      # 改权限
chown user:group f  # 改属主
```

---

## 4. 服务与日志

```bash
systemctl status nginx
systemctl restart nginx
journalctl -u nginx      # 看服务的 systemd 日志
journalctl -u nginx -f   # 实时跟踪
```

---

## 5. 网络

```bash
curl http://localhost:8000/health   # 发请求测接口
wget http://.../file                # 下载
ss -tlnp                            # 看监听端口
```

理解概念：**IP、Port、TCP、HTTP、DNS、反向代理（Nginx）**。

---

## 6. 最终能力

```text
SSH 进入 Linux 服务器
   ↓
启动 GeoAI 服务
   ↓
查看日志（journalctl / tail -f）
   ↓
查看 CPU / GPU（top / nvidia-smi）
   ↓
发现服务崩溃 / OOM / 显存不足
   ↓
定位问题
   ↓
重启 / 修复
```

---

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| 资源 | top/free/df/nvidia-smi |
| 进程权限 | ps/kill/chmod/chown |
| 日志 | journalctl |
| 网络 | curl/ss/反向代理 |

**核心认知**：工业级 Linux 的核心是「诊断」——服务崩了、显存爆了、CPU 飙了，你能登上去、查到原因、修好。`nvidia-smi` 看 GPU 是 GeoAI 与普通后端最大的不同。
