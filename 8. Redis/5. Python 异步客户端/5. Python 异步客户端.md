# 5. Python 异步客户端

> 配套可运行脚本：`5. Python 异步客户端.py`

## 0. 一句话结论

**用 `redis.asyncio.Redis` 把 Redis 融入 FastAPI 的 `async def` 路由——全程 `await`，等待 Redis 时不阻塞事件循环。这把 asyncio、FastAPI、Redis、PostgreSQL 串成一条链。**

---

## 1. 异步客户端

```python
from redis.asyncio import Redis

redis = Redis(
    host="localhost",
    port=6379,
    decode_responses=True
)
```

---

## 2. FastAPI 集成

```python
@app.get("/users/{user_id}")
async def get_user(user_id: int):
    key = f"user:{user_id}"

    cached = await redis.get(key)
    if cached:
        return cached

    # 查询数据库
    user = query_db(user_id)

    await redis.set(key, user, ex=3600)
    return user
```

关键：**全程 `await`**，等待 Redis 时不阻塞事件循环（呼应 asyncio 那一章）。

---

## 3. 完整技术链

```text
Python asyncio
     ↓
FastAPI（async def）
     ↓
Redis（异步缓存）
     ↓
PostgreSQL（业务数据）
```

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| redis.asyncio | 异步客户端 |
| await | 不阻塞事件循环 |
| 技术链 | asyncio → FastAPI → Redis → PG |

**核心认知**：同步 Redis 客户端会阻塞整个事件循环，异步客户端才能发挥 FastAPI 的并发优势。这是「会用 Redis」到「在异步后端正确用 Redis」的分水岭。
