# 4. 常用功能：计数器 / 限流 / Session / 分布式锁

> 配套可运行脚本：`4. 常用功能.py`

## 0. 一句话结论

**Redis 除了缓存，还有四个高频功能：计数器（INCR 原子自增）、限流（计数 + 过期）、Session（带 TTL 的登录态）、分布式锁（SET NX EX 原子加锁）。**

---

## 1. 计数器

```python
r.incr("page:views")   # 每次 +1，原子操作
```

`INCR` 是原子的：并发下也不会少加。

---

## 2. 限流

```python
def allow_request(user_id, limit=5, window=60):
    key = f"rate:{user_id}"
    count = r.incr(key)
    if count == 1:
        r.expire(key, window)   # 第一次请求时开窗口
    return count <= limit
```

原理：**计数器 + 过期时间**——窗口内计数，超限拒绝。

---

## 3. Session

```python
r.set("session:abc123", "user_id=1001", ex=1800)   # 30 分钟
```

带 TTL 的键存登录态，过期自动失效，用户需重新登录。

---

## 4. 分布式锁

```python
r.set("lock:task", "worker1", nx=True, ex=10)   # 不存在才设置 + 过期
```

`SET key value NX EX` 语义：

- `NX`：key 不存在才设置（拿锁）
- `EX`：设过期（防止死锁）

用途：多个服务实例抢同一个任务时，保证只有一个拿到锁。

---

## 6. 小结

| 功能 | 关键命令 |
|------|----------|
| 计数器 | INCR |
| 限流 | INCR + EXPIRE |
| Session | SET + EX |
| 分布式锁 | SET NX EX |

**核心认知**：这些功能都建立在「Redis 单线程 + 原子命令」之上。原子性让计数、限流、加锁在并发下依然正确——这正是 Redis 的价值所在。
