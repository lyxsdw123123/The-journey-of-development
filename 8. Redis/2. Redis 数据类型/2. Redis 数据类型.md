# 2. Redis 数据类型

> 配套可运行脚本：`2. Redis 数据类型.py`

## 0. 一句话结论

**Redis 有 5 种核心数据类型：String（缓存/计数）、List（队列）、Set（去重）、Hash（存对象）、ZSet（排行榜）。后端最常用前 4 种。**

---

## 1. 五种类型速览

| 类型 | 特点 | 典型用途 |
|------|------|----------|
| String | 单个值 | 缓存、计数器 |
| List | 有序、可重复 | 队列、时间线 |
| Set | 无序、去重 | 标签、共同关注 |
| Hash | 字段-值 | 存对象 |
| ZSet | 带分数、有序 | 排行榜 |

---

## 2. 常用命令

```python
# String
r.set("name", "Tom")
r.get("name")
r.incr("counter")              # 计数

# List
r.rpush("queue", "a", "b")     # 入队
r.lrange("queue", 0, -1)       # 全取
r.lpop("queue")                # 出队

# Set
r.sadd("tags", "gis", "ai")    # 去重
r.smembers("tags")

# Hash
r.hset("user:1", "name", "Tom")
r.hset("user:1", "age", "20")
r.hgetall("user:1")
# 注：Redis 4+ 可用 mapping={"name":"Tom","age":"20"} 一次写多个字段

# ZSet
r.zadd("scores", {"Tom": 90, "Amy": 95})
r.zrange("scores", 0, -1)      # 按分数升序
```

---

## 3. 怎么选类型

```text
存一个值（缓存）        -> String
存一串有序的东西（队列） -> List
存去重的集合（标签）     -> Set
存一个对象的字段         -> Hash
要排序（排行榜）         -> ZSet
```

## 5. 小结

| 类型 | 一句话 |
|------|--------|
| String | 缓存、计数 |
| List | 队列 |
| Set | 去重 |
| Hash | 存对象 |
| ZSet | 排行榜 |

**核心认知**：选对数据类型，能让 Redis 用最少的命令完成最多的事（如 Set 天然去重、ZSet 天然排序）。这是 Redis 设计之美。
