# 4. `__enter__` 与 `__exit__` 上下文管理器

> 配套可运行脚本：`4. __enter__与__exit__ 上下文管理器.py`

## 0. 一句话结论

**`__enter__` / `__exit__` 是「上下文管理器」协议，对应 `with` 语句——`__enter__` 进入时准备资源，`__exit__` 退出时释放资源，且异常也会释放。**

---

## 1. `with` 背后的秘密

```python
with open("test.txt") as f:
    data = f.read()
```

Python 内部等价于：

```text
f = open("test.txt")
f.__enter__()     # 进入 with：打开文件
data = f.read()   # 使用
f.__exit__()      # 退出 with：关闭文件
```

| 方法 | 时机 | 职责 |
|------|------|------|
| `__enter__` | 进入 `with` | 准备资源，返回值赋给 `as` 后面的变量 |
| `__exit__` | 退出 `with` | 释放资源，即使异常也执行 |

---

## 2. 自己实现

```python
class MyFile:
    def __enter__(self):
        print("打开资源")
        return self
    def __exit__(self, exc_type, exc_value, traceback):
        print("关闭资源")

with MyFile():
    print("使用资源")
```

输出：

```text
打开资源
使用资源
关闭资源
```

## 3. `__exit__` 的三个参数

`__exit__(self, exc_type, exc_value, traceback)` 接收三个参数：

| 参数 | 含义 |
|------|------|
| `exc_type` | 异常类型（无异常时为 `None`） |
| `exc_value` | 异常实例 |
| `traceback` | 回溯信息 |

```python
def __exit__(self, exc_type, exc_value, traceback):
    if exc_type is None:
        print("正常退出")
    else:
        print(f"异常退出: {exc_type.__name__}: {exc_value}")
    # return False：不吞异常，继续向外抛
    # return True ：吞掉异常
    return False
```

**关键**：即使 `with` 块内抛异常，`__exit__` 依然执行，资源依然被释放。

---

## 4. 为什么需要它：资源一定被释放

**错误写法**：

```python
f = open("a.txt")
data = f.read()   # 若 read 抛异常，f.close() 永远不执行 -> 文件泄漏
```

**正确写法**：

```python
with open("a.txt") as f:
    data = f.read()   # 无论是否异常，f.close() 一定执行
```

## 5. 后端实战：数据库连接

数据库操作最怕「连接忘了关」：

```python
with database.connection():
    # 进入 with：连接数据库
    # 查询数据
    # 退出 with：关闭连接
```

FastAPI 里大量类似：

```python
with Session(engine) as session:
    session.query(...)
```

**本质就是**：

```text
__enter__  建会话 / 建连接
   +
__exit__   关会话 / 关连接
```

即使查询抛异常，连接也会被安全关闭，不会泄漏。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| `__enter__` | 进入 `with`，准备资源 |
| `__exit__` | 退出 `with`，释放资源 |
| 三个参数 | 异常类型/实例/回溯 |
| 异常安全 | 块内异常也保证释放 |
| 应用 | 文件、数据库、锁等资源管理 |

**核心认知**：`with` = `__enter__` + `__exit__`，是 Python 保证「资源用完必释放」的机制，后端开发几乎无处不在。
