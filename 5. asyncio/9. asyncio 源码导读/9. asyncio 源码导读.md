# 9. asyncio 源码导读

> 配套可运行脚本：`9. asyncio 源码导读.py`

## 0. 一句话结论

**想真正吃透 asyncio，最终要读 `Lib/asyncio/` 源码。但不要一上来就从头读——先懂概念，再自己写，最后带着问题读源码。**

---

## 1. 三阶段学习路线

```text
第一阶段：理解 async / await / Coroutine / Task / Future / Event Loop
   （前面 8 节就是这个阶段）

第二阶段：自己写 asyncio.run / create_task / gather / sleep

第三阶段：读源码
```

---

## 2. 核心文件

```text
asyncio/
├── events.py        # 事件循环、Future、Task 的接口
├── tasks.py         # Task、gather、sleep、create_task
├── futures.py       # Future 实现
└── base_events.py   # 事件循环基础实现
```

（`asyncio.__file__` 可以定位到你的 Python 安装里的源码目录。）

---

## 3. 重点追什么

```text
asyncio.run()
   ↓
Event Loop（events.py / base_events.py）
   ↓
create_task()（tasks.py）
   ↓
Task（tasks.py，是 Future 子类）
   ↓
Future（futures.py）
   ↓
_event_loop 调度 I/O
```

**不要逐行读，带着问题追**：

- `asyncio.run` 里到底做了什么？
- `create_task` 如何把协程变成 Task？
- `await` 一个 Future 时，事件循环怎么「暂停 / 恢复」？

---

## 4. 动手清单

1. 运行脚本：

   ```bash
   python "9. asyncio 源码导读.py"
   ```

2. 用 `python -c "import asyncio; print(asyncio.__file__)"` 找到源码目录，打开 `tasks.py` 看 `create_task`。

3. 挑战：在 `futures.py` 里找 `Future.__await__`，思考 `await future` 是如何工作的。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 三阶段 | 懂概念 → 自己写 → 读源码 |
| 核心文件 | events / tasks / futures / base_events |
| 追踪路径 | run → Event Loop → create_task → Task → Future |

**核心认知**：源码是「最终答案」，但要有前 8 节的概念和动手经验垫底，否则硬啃源码会迷失。带着问题追调用链，事半功倍。
