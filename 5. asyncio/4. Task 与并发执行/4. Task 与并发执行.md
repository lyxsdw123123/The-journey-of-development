# 4. Task 与并发执行

> 配套可运行脚本：`4. Task 与并发执行.py`

## 0. 一句话结论

**直接 `await` 两个协程是串行；用 `asyncio.create_task()` 创建 Task 才是并发——Task 把协程提交给事件循环调度，多个任务同时推进。**

---

## 1. 顺序 await（串行）

```python
async def task1():
    await asyncio.sleep(1)
    print("task1")

async def task2():
    await asyncio.sleep(1)
    print("task2")

await task1()   # 等 1 秒
await task2()   # 再等 1 秒
```

```text
task1 ──等待1s──> 完成
                   task2 ──等待1s──> 完成
```

**总耗时 2 秒**——本质还是串行。

---

## 2. create_task（并发）

```python
t1 = asyncio.create_task(task1())
t2 = asyncio.create_task(task2())
await t1
await t2
```

```text
Task1 ──等待1s──────> 完成
      ↘
Task2 ──等待1s──────> 完成
      ↗
```

**总耗时 1 秒**——两个任务同时等待，事件循环同时调度。

---

## 3. 关键区别

| | 顺序 `await` | `create_task` |
|--|--------------|---------------|
| 执行方式 | 串行 | 并发 |
| 两个 1 秒任务 | 2 秒 | 1 秒 |
| 本质 | 一个个等 | 提交给事件循环 |

> `create_task` 是进入「真正 asyncio」的分界线——从这一刻起，多个任务才真正被事件循环并发调度。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 顺序 await | 串行，一个个等 |
| create_task | 创建 Task，并发调度 |
| Task | 被事件循环调度的协程 |

**核心认知**：协程本身不并发，只有变成 Task 交给事件循环，才能真正并发执行。`create_task` 是「把协程提交给调度器」的关键动作。
