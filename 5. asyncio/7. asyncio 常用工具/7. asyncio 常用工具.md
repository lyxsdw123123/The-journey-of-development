# 7. asyncio 常用工具

> 配套可运行脚本：`7. asyncio 常用工具.py`

## 0. 一句话结论

**掌握核心概念后，还要会用这些工具：`gather`（并发收集结果）、异步上下文管理器（`async with`）、异步迭代器（`async for`）、`Queue`（生产消费）、`Semaphore`（限流）。**

---

## 1. `asyncio.gather`

```python
results = await asyncio.gather(fetch(1), fetch(2), fetch(3))
# 并发执行三个，收集所有结果 -> ["结果1", "结果2", "结果3"]
```

最常用的「并发 + 收集结果」。

---

## 2. 异步上下文管理器（`async with`）

```python
class AsyncResource:
    async def __aenter__(self):
        print("打开")
        return self
    async def __aexit__(self, exc_type, exc, tb):
        print("关闭")

async with AsyncResource():
    print("使用")
```

对应数据库：`async with db.connection()`——异步版 `with`。

---

## 3. 异步迭代器（`async for`）

```python
class AsyncCounter:
    def __aiter__(self):
        return self
    async def __anext__(self):
        if self.i >= self.n:
            raise StopAsyncIteration
        self.i += 1
        return self.i

async for x in AsyncCounter(3):
    print(x)
```

---

## 4. `asyncio.Queue`：生产-消费

```python
q = asyncio.Queue()
await asyncio.gather(producer(q), consumer(q))
```

生产者 `put`，消费者 `get`，异步流水线。

---

## 5. `asyncio.Semaphore`：限制并发

```python
sem = asyncio.Semaphore(2)   # 最多 2 个并发

async def limited(name):
    async with sem:
        await do_work()
```

用途：爬虫限流、限制数据库并发连接数，避免打爆下游。

> 还有 `asyncio.Lock`（互斥锁）、`asyncio.wait`（细粒度等待）、`asyncio.wait_for`（超时）。

## 7. 小结

| 工具 | 用途 |
|------|------|
| `gather` | 并发 + 收集结果 |
| `async with` | 异步资源管理 |
| `async for` | 异步遍历 |
| `Queue` | 生产-消费 |
| `Semaphore` | 限制并发 |

**核心认知**：这些工具是异步后端（爬虫、API、流处理）的日常积木——`gather` 并发、`async with` 管资源、`Semaphore` 限流。
