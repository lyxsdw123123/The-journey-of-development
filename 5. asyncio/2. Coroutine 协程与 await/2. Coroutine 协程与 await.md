# 2. Coroutine 协程与 await

> 配套可运行脚本：`2. Coroutine 协程与 await.py`

## 0. 一句话结论

**`async def` 函数调用后返回「协程对象」，不会直接执行；`await` 不是简单等待，而是「当前协程让出执行权，等结果好了再继续」。**

---

## 1. 协程（Coroutine）

```python
async def hello():
    print("hello")

result = hello()   # 不会打印 hello！
print(result)      # <coroutine object hello at ...>
```

```text
hello()
   ↓
Coroutine Object（协程对象）
```

**调用 `async def` 函数只是拿到协程对象，函数体还没执行。**

对比普通函数：

```python
def hello():
    return "hello"
hello()   # 立即执行，返回 "hello"
```

---

## 2. 真正执行协程：`asyncio.run()`

```python
import asyncio

async def hello():
    print("hello")

asyncio.run(hello())   # 创建事件循环，真正执行
```

---

## 3. await 的本质

```python
async def main():
    result = await database.query()
```

不要简单理解成「等待数据库」，更准确的是：

```text
await database.query()
   ↓
当前协程暂时让出执行权
   ↓
Event Loop 去处理其他任务
   ↓
数据库返回
   ↓
继续执行当前协程
```

**`await` = 让出执行权 + 等结果。这是 asyncio 最重要的思想之一。**

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 协程 | `async def` 定义的异步函数 |
| 协程对象 | 调用后得到的对象，不直接执行 |
| `asyncio.run` | 驱动协程执行 |
| `await` | 让出执行权 + 等结果 |

**核心认知**：协程是「可暂停、可恢复」的函数。`await` 是暂停点——暂停时把控制权交还给事件循环，这是异步并发的根基。
