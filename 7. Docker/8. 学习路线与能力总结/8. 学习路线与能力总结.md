# 8. 学习路线与能力总结

> 配套可运行脚本：`8. 学习路线与能力总结.py`

## 0. 一句话结论

**学完 Docker，你的 Python 后端能力就串起来了——从「会调用 FastAPI 的学生」，变成「能理解运行机制并独立构建、部署后端系统的开发者」。**

---

## 1. Docker 学习顺序

```text
Docker
  ↓
① Image → ② Container → ③ docker run → ④ Dockerfile → ⑤ Port
  ↓
⑥ Volume → ⑦ Network → ⑧ Docker Compose
  ↓
⑨ FastAPI + PostgreSQL + Redis → ⑩ Nginx → 完整后端部署
```

> 不要一上来就学 Kubernetes，先把 Docker 这条链走扎实。

---

## 2. 完整后端能力链

```text
Python
  ├── Python运行机制
  ├── OOP / 魔术方法
  ├── 装饰器 / 生成器
  └── 异常 / 类型 / 工程规范
        ↓
    asyncio → SQL → PostgreSQL → FastAPI → FastAPI源码
        ↓
     Docker
        ↓
 ┌──────┼──────┐
FastAPI PostgreSQL Redis
 └──────┼──────┘
        ↓
      Nginx → 后端部署
```

---

## 3. 身份的转变

| 之前 | 之后 |
|------|------|
| 会调用 FastAPI 的 Python 学生 | 能理解运行机制、独立构建部署的开发者 |

你前面学的 **asyncio + FastAPI 源码 + SQL/PostgreSQL + Docker**，正好是一条非常完整的 Python 后端进阶路线。

---

## 4. 动手清单

1. 运行脚本：

   ```bash
   python "8. 学习路线与能力总结.py"
   ```

2. 复盘：默写一遍从「Python」到「后端部署」的完整能力链。

3. 挑战：找一个自己写的 FastAPI 项目，亲手把它容器化并 `docker compose up` 跑起来。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 学习顺序 | 概念 → Dockerfile → Compose → 实战 |
| 能力链 | Python → ... → Docker → 部署 |
| 终点 | 独立构建、部署后端系统 |

**核心认知**：Docker 是「工程化」的最后一环——它把你学到的所有后端知识，封装成可一键部署的系统。这一刻，你从「学习者」真正走向「开发者」。
