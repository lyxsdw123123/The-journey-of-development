# 5. Dockerfile 详解

> 配套可运行脚本：`5. Dockerfile 详解.py`

## 0. 一句话结论

**Dockerfile 告诉 Docker「如何构建我的应用镜像」。核心指令：`FROM`（基础镜像）、`WORKDIR`（工作目录）、`COPY`（复制文件）、`RUN`（构建时执行）、`CMD`（启动时执行）。**

---

## 1. 完整 Dockerfile

```dockerfile
FROM python:3.12

WORKDIR /app

COPY requirements.txt .

RUN pip install -r requirements.txt

COPY . .

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

---

## 2. 逐行理解

| 指令 | 作用 |
|------|------|
| `FROM python:3.12` | 以 Python 3.12 为基础环境 |
| `WORKDIR /app` | 设置容器内工作目录 |
| `COPY requirements.txt .` | 复制依赖清单进容器 |
| `RUN pip install -r requirements.txt` | 构建时安装依赖 |
| `COPY . .` | 复制项目代码 |
| `CMD [...]` | 容器启动时执行的命令 |

---

## 3. `0.0.0.0` vs `127.0.0.1`

| 地址 | 含义 |
|------|------|
| `127.0.0.1` | 只监听本机（容器内部），外部访问不到 |
| `0.0.0.0` | 监听所有接口，允许外部访问 |

容器是隔离环境，必须监听 `0.0.0.0`，外部才能通过端口映射访问到 FastAPI。

---

## 4. COPY 顺序的讲究（缓存）

```dockerfile
COPY requirements.txt .   # 先复制依赖（变化少）
RUN pip install ...       # 依赖安装层可缓存
COPY . .                  # 再复制代码（变化多）
```

好处：只改代码时，`pip install` 不重跑，构建更快。

---

## 6. 小结

| 指令 | 一句话 |
|------|--------|
| FROM | 基础镜像 |
| WORKDIR | 工作目录 |
| COPY | 复制文件 |
| RUN | 构建时执行 |
| CMD | 启动时执行 |

**核心认知**：Dockerfile 把「装环境 + 装依赖 + 跑应用」固化成镜像构建流程。理解每行，就能把自己任何 Python 项目容器化。
