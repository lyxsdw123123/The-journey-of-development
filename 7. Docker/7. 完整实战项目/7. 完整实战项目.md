# 7. 完整实战项目

> 配套可运行脚本：`7. 完整实战项目.py`

## 0. 一句话结论

**最终目标：把 FastAPI + PostgreSQL + Redis + Nginx 全部容器化，`docker compose up -d` 一条命令启动完整后端。**

---

## 1. 项目结构

```text
backend/
├── app/
│   ├── main.py
│   ├── routers/
│   ├── models/
│   ├── services/
│   └── database/
├── requirements.txt
├── Dockerfile
├── compose.yaml
├── .dockerignore
└── .env
```

- `.dockerignore`：告诉 Docker 哪些文件不复制进镜像（`.git`、`__pycache__`）。
- `.env`：存放敏感配置（数据库密码），不进 git。

---

## 2. 完整 compose.yaml

```yaml
services:
  nginx:
    image: nginx:latest
    ports: ["80:80"]
    depends_on: [api]

  api:
    build: .
    expose: ["8000"]
    depends_on: [db, redis]
    environment:
      DATABASE_URL: postgresql://postgres:password@db:5432/app
      REDIS_URL: redis://redis:6379

  db:
    image: postgres:17
    environment: {...}
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:latest

volumes:
  postgres_data:
```

架构：

```text
Nginx（80，反向代理）→ FastAPI（8000）→ PostgreSQL / Redis
```

---

## 3. 一键启动

```bash
docker compose up -d
docker compose ps    # 看到 api / db / redis / nginx 全部运行
```

---

## 4. 请求链路（容器化后）

```text
浏览器 → :80 → Nginx → api:8000 → { db:5432, redis:6379 }
```

---

## 6. 小结

| 概念 | 一句话 |
|------|--------|
| 项目结构 | app + Dockerfile + compose + .env |
| 四服务 | nginx + api + db + redis |
| 一键启动 | docker compose up -d |

**核心认知**：容器化不是「会写 Dockerfile」，而是「能把整个后端系统（服务、数据库、缓存、代理）描述成一键启动的配置」。这是工程化的落地能力。
