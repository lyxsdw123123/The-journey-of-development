# 6. Docker Compose 多容器编排

> 配套可运行脚本：`6. Docker Compose 多容器编排.py`

## 0. 一句话结论

**单容器用 Dockerfile；多容器（FastAPI + PostgreSQL + Redis + Nginx）用 Docker Compose 统一编排，一条命令 `docker compose up` 全部启动。**

---

## 1. 完整 compose.yaml

```yaml
services:
  api:
    build: .
    ports:
      - "8000:8000"
    depends_on:
      - db
      - redis

  db:
    image: postgres:17
    environment:
      POSTGRES_DB: app
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:latest

volumes:
  postgres_data:
```

---

## 2. 逐字段理解（不要死记 YAML）

| 字段 | 含义 |
|------|------|
| `services` | 定义所有服务（容器） |
| `build: .` | 用当前目录 Dockerfile 构建镜像 |
| `image` | 直接用现成镜像 |
| `ports` | 端口映射 `宿主机:容器` |
| `environment` | 环境变量 |
| `depends_on` | 依赖关系（先启动 db、redis） |
| `volumes` | 数据卷持久化 |

---

## 3. 常用 compose 命令

| 命令 | 作用 |
|------|------|
| `docker compose up` | 前台启动 |
| `docker compose up -d` | 后台启动 |
| `docker compose down` | 停止并删除容器 |
| `docker compose ps` | 查看状态 |
| `docker compose logs -f` | 跟踪日志 |
| `docker compose build` | 重新构建 |

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| Compose | 多容器编排 |
| services | 一组服务 |
| compose up | 一键启动 |

**核心认知**：Docker Compose 把「多容器后端」描述成一个 YAML 文件，实现一键启动、可复现的完整环境。这是工程化的核心能力。
