# 2. Image 与 Container

> 配套可运行脚本：`2. Image 与 Container.py`

## 0. 一句话结论

**Image（镜像）是「打包好的环境模板」，Container（容器）是「镜像运行起来的实例」。关系：`Image → 运行 → Container`。**

---

## 1. Image 镜像

> 一个已经打包好的运行环境模板。

```text
python:3.12
postgres:17
redis:latest
nginx:latest
```

```bash
docker pull python:3.12   # 下载 Python 3.12 镜像
```

**镜像本身不是正在运行的程序**，只是模板。

---

## 2. Container 容器

> 镜像运行起来之后的实例。

```text
Image
   ↓ 运行
Container
```

```bash
docker run python:3.12   # 用镜像创建容器
```

---

## 3. 类比：类与对象

| Docker | 类比 |
|--------|------|
| Image（镜像） | 类 class / 菜谱 |
| Container（容器） | 对象 instance / 一盘菜 |

一个镜像可以运行出多个容器实例。

---

## 4. 常用命令

| 命令 | 作用 |
|------|------|
| `docker images` | 查看本地镜像 |
| `docker pull <镜像>` | 下载镜像 |
| `docker run <镜像>` | 运行容器 |
| `docker ps` | 查看运行中的容器 |
| `docker ps -a` | 查看所有容器（含停止的） |
| `docker rm <容器>` | 删除容器 |
| `docker rmi <镜像>` | 删除镜像 |

---

## 6. 小结

| 概念 | 一句话 |
|------|--------|
| Image | 环境模板 |
| Container | 模板运行出的实例 |
| 关系 | Image → 运行 → Container |

**核心认知**：区分「镜像」和「容器」是 Docker 一切的基础。镜像不变、可复用；容器是运行中的、会消亡的实例（数据要存到 Volume，见下节）。
