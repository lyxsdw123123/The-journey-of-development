# 7. 最终项目：GeoAI Agent

## 0. 一句话结论

**不要做两个独立项目，直接做一个大的——「自然语言空间分析系统」：用户用中文问空间问题，系统通过 RAG + MCP + PostGIS 给出答案和地图。这把你前面学的 Python/FastAPI/SQL/PostgreSQL/Redis/Docker/Linux 全部变成一个完整工程。**

---

## 1. 系统架构

```text
                用户
                 ↓
        "长沙有哪些高校？"
                 ↓
              FastAPI
                 ↓
              GeoAI Agent
                 │
       ┌─────────┼─────────┐
       ↓         ↓         ↓
     RAG       MCP       PostGIS
       │         │         │
       ↓         ↓         ↓
   GIS文档    GIS Tools   空间数据
                 │
                 ↓
            空间分析
                 ↓
            GeoJSON
                 ↓
             地图前端
```

---

## 2. 四阶段演进

### 第一阶段：自然语言查询

```text
用户：长沙有哪些高校？
Agent：调用 query_schools()
返回：湖南大学、中南大学、湖南师范大学…
```

### 第二阶段：空间查询

```text
用户：长沙距离地铁站 500 米以内的高校有哪些？
Agent：自动生成 ST_DWithin(...)，返回地图
```

### 第三阶段：空间分析

```text
用户：找出长沙适合建设新商业中心的区域。
Agent 调用：人口数据 + 道路 + 地铁 + 商业设施 + 空间分析工具
最终：数据 → 空间分析 → GeoAI → 地图
```

### 第四阶段：多模态

```text
用户上传一张地图/遥感影像：
图片 → Multimodal LLM → GeoAI Agent → GIS 工具 → PostGIS → 分析结果
```

---

## 3. 项目定位

这不是简单的：

> Python 调一个大模型 API

而是一个真正的：

> **AI + GIS + Backend + Database + Agent 系统**

---

## 4. 动手清单

1. 先搭最小闭环：FastAPI + PostGIS，做一个 `query_schools(city)` 接口返回 GeoJSON。

2. 再加 Agent：让 LLM 能调用 `query_schools` 这个工具。

3. 逐步加入 RAG（GIS 文档）、MCP（GIS 工具）、多模态，四阶段迭代。
