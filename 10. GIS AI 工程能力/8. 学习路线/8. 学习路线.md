# 8. 学习路线

## 0. 一句话结论

**建议严格按 4 个月顺序推进：第 1 个月空间数据库，第 2 个月 RAG/GeoRAG，第 3 个月 Agent/MCP，第 4 个月多模态 + 完整系统 + Docker 部署。**

---

## 1. 4 个月学习顺序

```text
第 1 个月
PostgreSQL → PostGIS → 空间数据库 → 空间 SQL

第 2 个月
RAG → Vector Database → GeoRAG → Agent

第 3 个月
Agent → Tool Calling → MCP → GIS Tools

第 4 个月
多模态模型 → GeoAI Agent → 自然语言空间分析系统 → Docker 部署
```

---

---

## 3. 身份的转变

不是：

> Python 后端工程师

而是：

> **Python Backend + AI Application + GeoAI**

---

## 4. 动手清单

1. 把 4 个月计划拆成「每周一个可交付的小目标」。

2. 第 1 个月结束时，完成「PostGIS 空间查询」能跑通；第 4 个月结束时，完成「自然语言空间分析系统」能 `docker compose up` 部署。

3. 挑战：回看这个仓库的 10 个主题，画一条你自己的「已学 → 待学」路线图。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 4 个月 | 空间库 → RAG → Agent/MCP → 多模态 |
| 技术栈 | Backend + AI + GeoAI |
| 终点 | 自然语言空间分析系统 |

**核心认知**：这条路线不是「学几个热门框架」，而是把 Python、FastAPI、SQL、PostgreSQL、Redis、Docker、Linux 全部沉淀成一个完整的 GeoAI 工程。至此，你从「会调库的学习者」成长为「能独立构建空间智能系统的工程师」。
