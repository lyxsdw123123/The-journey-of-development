# 6. 多模态 GeoAI

## 0. 一句话结论

**多模态让 GeoAI 从「文本 → GIS」升级到「文本/图像/地图/遥感 → GIS 分析」——你本身就是 GIS 专业，这一部分非常值得学。**

---

## 1. 从文本到多模态

```text
原来：Text → GIS

现在：Text
        ↓
     Multimodal LLM（多模态大模型）
        ↓
     Image / Map / Remote Sensing（图像/地图/遥感）
        ↓
     GIS Analysis（空间分析）
```

---

## 2. 应用场景

> 「分析这张遥感影像中的土地利用情况。」

> 「根据这张地图判断城市扩张区域。」

输入不再只是文本，而是：

```text
遥感影像 + 地图 + 文本 + 空间数据
        ↓
   Multimodal GeoAI
```

---

## 3. 多模态的价值

| 能力 | 说明 |
|------|------|
| 看遥感影像 | 识别土地利用、地物 |
| 读地图 | 理解空间分布 |
| 结合文本 | 用自然语言下指令 |
| 输出分析 | 结合 PostGIS 出结果 |

---

## 4. 动手清单

1. 理解多模态链路：图像/地图/遥感 → 多模态 LLM → GIS 分析。

2. 思考：一张遥感影像 + 一段文本 + 一份矢量数据，如何一起喂给 GeoAI？

3. 挑战：多模态模型「看地图」和「查 PostGIS 坐标」有什么区别？各自擅长什么？

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 多模态 | 文本 + 图像 + 地图 + 遥感 |
| 链路 | 多模态输入 → LLM → GIS 分析 |
| 价值 | 让 AI「看懂」空间数据 |

**核心认知**：多模态是 GeoAI 的高级形态——从「文字问答」走向「看图、读图、分析空间」。GIS 背景让你能理解这些空间数据的语义，这是纯 LLM 工程师不具备的优势。
