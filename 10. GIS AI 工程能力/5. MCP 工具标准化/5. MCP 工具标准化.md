# 5. MCP 工具标准化

## 0. 一句话结论

**MCP（Model Context Protocol）不要把当成「新框架」，而是「一种让 AI 发现和调用外部工具/资源的标准化方式」——统一 LLM 与工具之间的接口。**

---

## 1. MCP 是什么

```text
        LLM
         │
        MCP（标准化协议）
         │
  ┌──────┼────────┐
  ↓      ↓        ↓
PostGIS  GIS工具   文件系统
  ↓      ↓        ↓
空间查询  Buffer  Shapefile
```

MCP 让不同的工具以「统一的方式」被 AI 调用，而不是每个工具各写一套对接代码。

---

## 2. GIS 工具的 MCP 化

提供这些能力，Agent 就能调用：

```text
query_layer()         查询图层
spatial_query()       空间查询
buffer_analysis()     缓冲区分析
nearest_feature()     最近要素
intersect_analysis()  相交分析
```

---

## 3. 类比理解

| 概念 | 类比 |
|------|------|
| MCP | 工具界的「USB 接口」 |
| 工具（PostGIS/GIS） | 各种「外设」 |
| LLM | 使用外设的「主机」 |

有了统一接口，新工具「即插即用」。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| MCP | AI 调用工具的标准化方式 |
| 工具 | query_layer / spatial_query / buffer 等 |
| 价值 | 工具即插即用 |

**核心认知**：MCP 是「工具生态」的标准化层。对 GeoAI 来说，把 PostGIS、GIS 分析封装成标准 MCP 工具，你的空间能力就能被任何 LLM/Agent 调用——这是「GIS 能力 AI 化」的关键一步。
