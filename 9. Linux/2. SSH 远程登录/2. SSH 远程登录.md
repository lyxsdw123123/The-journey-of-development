# 2. SSH 远程登录

## 0. 一句话结论

**SSH 是后端工程师的必备技能——从本地电脑远程登录 Linux 服务器，在上面跑 FastAPI、PostgreSQL、Redis、Docker。**

---

## 1. 基本用法

```bash
ssh username@server_ip
```

例如：

```bash
ssh root@192.168.1.100
```

```text
本地电脑
   ↓ SSH
Linux 服务器
   ↓
运行 FastAPI / PostgreSQL / Redis / Docker
```

以后买云服务器、租 GPU 服务器、部署 GeoAI 项目，基本都会用到 SSH。

---

## 2. SSH Key 免密登录

```bash
ssh-keygen              # 生成一对密钥（本地）
ssh-copy-id user@server # 把公钥拷到服务器
```

之后 `ssh user@server` 就不用输密码了（用密钥认证）。

```text
本地：私钥（保密，留自己电脑）
服务器：公钥（放到 ~/.ssh/authorized_keys）
```

---

## 3. 常用 SSH 相关命令

```bash
ssh user@host                 # 登录
ssh -i key.pem user@host      # 用指定私钥登录（云服务器常见）
scp file user@host:/path      # 传文件到服务器
scp -r dir user@host:/path    # 传目录
```

---

## 4. 动手清单

1. 用 WSL 或云服务器练一次 `ssh-keygen` + `ssh-copy-id`。

2. 用 `scp` 把一个本地文件传到服务器。

3. 挑战：为什么「私钥」绝对不能泄露？`~/.ssh/authorized_keys` 里存的是什么？

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| SSH | 远程登录服务器 |
| ssh-keygen | 生成密钥对 |
| ssh-copy-id | 免密登录 |
| scp | 传文件 |

**核心认知**：SSH 是你和服务器之间的「桥梁」。所有部署、排查、运维，都从「SSH 登进去」开始。掌握密钥登录是安全和效率的基础。
