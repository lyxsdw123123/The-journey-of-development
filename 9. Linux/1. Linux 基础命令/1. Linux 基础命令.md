# 1. Linux 基础命令

## 0. 一句话结论

**后端开发不要求成为 Linux 运维，但必须能独立运行、排查、部署项目。第一步是掌握最常用的命令，并理解文件/目录/权限/进程/环境变量/端口/服务这几个核心概念。**

---

## 1. 最常用的命令

```bash
pwd       # 显示当前目录
ls        # 列出文件
cd        # 切换目录
mkdir     # 创建目录
cp        # 复制
mv        # 移动 / 重命名
rm        # 删除
touch     # 创建空文件
cat       # 查看文件（一次性输出）
less      # 分页查看文件
```

---

## 2. 重点不是背命令，而是理解概念

| 概念 | 含义 |
|------|------|
| 文件 | 一切皆文件（配置、日志、进程信息） |
| 目录 | 组织文件的层级结构 |
| 权限 | 谁能读/写/执行（`chmod`、`chown`） |
| 进程 | 正在运行的程序 |
| 环境变量 | 进程的配置（`PATH`、`DATABASE_URL`） |
| 端口 | 进程对外通信的通道（8000/5432/6379） |
| 服务 | 常驻后台的进程（由 systemd 管理） |

---

## 3. 常用命令速查

```bash
ls -la              # 列出所有文件（含隐藏）+ 权限
cd /opt/myapp       # 进入目录
mkdir -p a/b/c      # 递归创建目录
cp -r src dst       # 复制目录
mv old new          # 重命名
rm -rf dir          # 递归删除（慎用！）
cat config.yaml     # 看配置文件
less app.log        # 分页看日志（q 退出）
```

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 常用命令 | pwd/ls/cd/mkdir/cp/mv/rm/touch/cat/less |
| 核心概念 | 文件/目录/权限/进程/环境变量/端口/服务 |

**核心认知**：Linux 是后端项目的「运行现场」。会用命令只是第一步，理解「文件、进程、端口、服务」这些概念，才能在服务器上自如地排查和部署。
