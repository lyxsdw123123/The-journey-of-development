# 3. systemctl 服务管理

## 0. 一句话结论

**Linux 上大量后台服务由 systemd 管理，用 `systemctl` 命令启动/停止/重启/查看状态/设置开机自启。**

---

## 1. 常用命令

```bash
systemctl status nginx     # 查看状态
systemctl start nginx      # 启动
systemctl stop nginx       # 停止
systemctl restart nginx    # 重启
systemctl enable nginx     # 开机自启
systemctl disable nginx    # 取消开机自启
```

---

## 2. 模型

```text
systemd（系统服务管理器）
   ↓
service（服务单元，如 nginx、postgresql、redis）
   ↓
启动 / 停止 / 重启 / 查看状态
```

---

## 3. 常用服务的服务名

| 服务 | 服务名 |
|------|--------|
| Nginx | `nginx` |
| PostgreSQL | `postgresql` |
| Redis | `redis` / `redis-server` |

```bash
systemctl status postgresql
systemctl restart redis
```

---

## 4. 动手清单

1. 在 Linux 上装 nginx，用 `systemctl start/enable/status nginx` 管理它。

2. 观察 `systemctl status nginx` 输出的「Active: active (running)」含义。

3. 挑战：`systemctl enable`（开机自启）和 `systemctl start`（立即启动）有什么区别？

---

## 5. 小结

| 命令 | 作用 |
|------|------|
| status | 查看状态 |
| start/stop/restart | 启动/停止/重启 |
| enable/disable | 开机自启/取消 |

**核心认知**：systemctl 是 Linux 上「管服务」的统一入口。你的 FastAPI（常配成 systemd 服务）、Nginx、PostgreSQL、Redis 都靠它守护和重启。部署项目时，把服务交给 systemd 管理是标配。
