# 8. 排错全景与最终技术栈

## 0. 一句话结论

**Linux 不用学成独立专业，达到「能独立维护自己的后端项目」就够了：SSH 登录 → 查文件 → 启动服务 → 查进程 → 查端口 → 查日志 → grep 定位 → 改配置 → 重启。**

---

## 1. 排错全景

```text
SSH 登录服务器
       ↓
查看文件（ls / cat）
       ↓
启动服务（systemctl）
       ↓
查看进程（ps / top）
       ↓
查看端口（ss / lsof）
       ↓
查看日志（tail -f / docker logs）
       ↓
grep 定位错误
       ↓
修改配置（vim）
       ↓
重启服务（systemctl restart）
```

---

## 2. 一句话串起来

> **能够独立维护自己的后端项目。**

不需要成为 Linux 运维专家，但服务出问题时，能自己登上去、查出来、改好、重启。

---

## 4. 身份的转变

不是单纯的：

> Python 后端工程师

而是：

> **Python Backend + AI Application + GeoAI**

你正在学的 **FastAPI → asyncio → SQL/PostgreSQL → Redis → Docker → Linux → LangChain/Agent/LLM → GIS/GeoAI**，是一条完整的技术链。

---

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| 排错全景 | 登进去 → 查 → 改 → 重启 |
| 最终目标 | 独立维护后端项目 |
| 技术栈 | Backend + AI + GeoAI |

**核心认知**：Linux 是你整个后端 + AI + GeoAI 技术栈的「地基」。前面的 FastAPI、PostgreSQL、Redis、Docker 最终都跑在 Linux 上——会 Linux，才算真正能「部署和维护」。
