# 6. Vim 基础

## 0. 一句话结论

**不用成为 Vim 高手，只要会「打开文件 → 修改 → 保存 → 退出」就够了——目标是服务器上没有 VS Code 时，你依然能改配置文件。**

---

## 1. 最小可用操作

```bash
vim app.py        # 打开文件
```

进入编辑：

```text
i                 # 进入插入模式（开始输入）
```

保存退出：

```text
Esc               # 回到命令模式
:wq               # 保存并退出
```

不保存强制退出：

```text
Esc
:q!               # 放弃修改，强制退出
```

---

## 2. 三种模式

| 模式 | 进入 | 作用 |
|------|------|------|
| 普通模式 | 启动后默认 | 移动、删除、执行命令 |
| 插入模式 | 按 `i` | 输入文字 |
| 命令行模式 | 按 `:` | 保存、退出、查找 |

记忆：**`i` 进去写，`Esc` 出来，`:wq` 存了走，`:q!` 不存走。**

---

## 3. 几个救命命令

```text
:q!      放弃修改退出（改错了就跑）
:w       只保存不退出
u        撤销
/word    搜索（n 下一个）
```

---

## 4. 动手清单

1. 在 Linux 里 `vim test.txt`，按 `i` 输入几行，`Esc` + `:wq` 保存退出。

2. 再打开，随便改点东西，用 `:q!` 放弃退出，确认文件没变。

3. 挑战：为什么 Vim 要有「普通模式 / 插入模式」之分，而不是像记事本一样打开就能打字？

---

## 5. 小结

| 操作 | 含义 |
|------|------|
| `i` | 进入编辑 |
| `Esc` | 回到命令模式 |
| `:wq` | 保存退出 |
| `:q!` | 不保存退出 |

**核心认知**：服务器上改配置（nginx.conf、.env、docker-compose.yaml）离不开命令行编辑器。Vim 学会这几个键，就够应付 90% 的场景了。
