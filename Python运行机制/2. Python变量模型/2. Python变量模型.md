# 2. Python 变量模型（非常重要）

> 配套可运行脚本：`2. Python变量模型.py`

## 0. 一句话结论

**Python 的变量不是「装数据的盒子」，而是贴在对象上的「名字」。变量保存的是「对象引用」（指向对象的指针），不是数据本身。赋值 `b = a` 复制的是引用，不是对象。**

---

## 1. 最常见的误解

很多初学者的理解：

```python
a = [1, 2, 3]
b = a
```

误以为：**「a 里面的数据被复制了一份给 b」** —— 这是错的。

真相是：

```text
        +-----------+
        | [1, 2, 3] |      <- 列表对象（真正存数据的地方）
        +-----------+
              ↑
              |
           对象地址

   a  --------|           a 保存的是「指向对象的引用」
   b  --------|           b 也保存指向「同一个」对象的引用
```

`a` 和 `b` 各自只保存了一个「对象地址（引用）」，它们指向**同一个列表对象**。

---

## 2. 验证：`id()` 与 `is`

```python
a = [1, 2, 3]
b = a

print(id(a))   # 例如 140123456
print(id(b))   # 140123456 —— 完全相同！
print(a is b)  # True
```

- `id(x)` 返回对象在内存中的地址（CPython 中即内存地址）。
- 两个变量的 `id` 相同，说明它们是**同一个对象**。

于是：

```python
b.append(4)
print(a)   # [1, 2, 3, 4]
```

执行 `b.append(4)` 的完整过程：

```text
找到 b
  ↓
找到 b 指向的列表对象
  ↓
修改那个列表对象（在末尾加 4）
```

因为 `a` 也指向这个对象，所以 `a` 看到的数据自然变了。

---

## 3. 可变对象 vs 不可变对象

这是理解「为什么 int 看起来不一样」的关键。

| 类型 | 可变？ | 行为 |
|------|--------|------|
| `list` / `dict` / `set` | 可变 | 可以**原地修改**，所有引用者都看到变化 |
| `int` / `str` / `tuple` | 不可变 | 无法原地改，只能**创建新对象 + 重新绑定** |

```python
x = 10
y = x
y = 20      # 不是把 10 改成 20，而是让 y 重新指向新对象 20
print(x)    # 10  —— 10 这个对象从没变过
```

```python
a = [1, 2]
b = a
b.append(3) # 原地修改，a、b 都变
print(a)    # [1, 2, 3]
```

**心法**：判断「改的是引用，还是改的对象」——`=` 改的是引用（重新绑定），方法调用（如 `append`）改的是对象。

## 4. `is` 与 `==` 的区别

| 运算符 | 比较什么 | 示例 |
|--------|----------|------|
| `is` | **身份**：是不是同一个对象 | `a is b` |
| `==` | **值**：内容是否相等 | `a == b` |

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True  内容相同
print(a is b)   # False 不是同一个对象
```

> 工程建议：和 `None` 比较用 `is`（`x is None`），其余多数场景用 `==`。

## 5. 浅拷贝 vs 深拷贝

想「真正复制一份、互不影响」时，用 `copy` 模块：

```python
import copy

original = [[1, 2], [3, 4]]

shallow = copy.copy(original)    # 浅拷贝：只复制最外层，内层仍共享
deep = copy.deepcopy(original)   # 深拷贝：递归复制每一层

shallow[0].append(999)
print(original)   # [[1, 2, 999], [3, 4]]  —— 被影响！

deep[0].append(999)
print(original)   # 不受影响（deep 是独立副本）
```

```text
浅拷贝 shallow：          深拷贝 deep：
shallow ──> [ , ]        deep ──> [ , ]
             │  │                 │  │
             ↓  ↓                 ↓  ↓
original[0]=[1,2] [3,4]   各自独立的 [1,2] [3,4]
             ↑
shallow[0] 共享这个内层列表
```

## 6. 函数传参：也是引用传递

```python
def mutate(lst):
    lst.append("加了")   # 改对象：影响调用方

def rebind(lst):
    lst = ["新列表"]     # 改引用：不影响调用方

data = [1, 2]
mutate(data)   # data 变了 -> [1, 2, '加了']
rebind(data)   # data 没变 -> 函数里只是把形参重新绑定
```

一句话：**函数可以修改传入的可变对象，但无法替换调用方手里的引用。**

## 8. 小结

| 概念 | 一句话 |
|------|--------|
| 变量 | 名字 + 引用，不是容器 |
| 赋值 | 复制引用，不复制对象 |
| 可变/不可变 | 决定「能否原地改」 |
| `is` / `==` | 身份 / 值 |
| 浅拷贝 / 深拷贝 | 复制一层 / 递归复制所有层 |

**核心认知**：`id()` 相同就是同一个对象；`b = a` 之后，改 `b` 通常也在改 `a`（除非你重新绑定 `b`）。
