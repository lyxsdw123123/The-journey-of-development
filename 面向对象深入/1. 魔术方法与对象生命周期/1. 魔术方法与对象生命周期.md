# 1. 魔术方法与对象生命周期

> 配套可运行脚本：`1. 魔术方法与对象生命周期.py`

## 0. 一句话结论

**魔术方法（Magic Methods / Dunder Methods）就是 Python 给对象定义的「协议接口」——你实现这些方法，Python 在特定场景会自动调用它们。**

---

## 1. 什么是魔术方法

「Dunder」= **Double Under**score（双下划线），所以魔术方法也叫 **dunder methods**，如 `__init__`、`__str__`、`__call__`。

核心例子：

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return self.name

user = User("Tom")

print(user)   # Tom
```

你没有调用 `user.__str__()`，但 `print(user)` 时 Python **自动**执行了 `user.__str__()`。

```text
print(user)
   ↓
str(user)
   ↓
user.__str__()   ->  "Tom"
```

这就是「协议接口」：

- **你负责实现** `__str__`；
- **Python 负责调用**，调用时机由协议规定（`print`、`str()`、格式化时都会触发）。

---

## 2. `__str__` vs `__repr__`

| 方法 | 触发场景 | 面向谁 | 风格 |
|------|----------|--------|------|
| `__str__` | `print(obj)`、`str(obj)` | 用户 | 友好、简洁 |
| `__repr__` | `repr(obj)`、交互式、调试、列表内元素 | 开发者 | 信息完整、可还原 |

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    def __str__(self):
        return f"({self.x}, {self.y})"
    def __repr__(self):
        return f"Point(x={self.x}, y={self.y})"

p = Point(3, 4)
print(p)       # (3, 4)
print(repr(p)) # Point(x=3, y=4)
print([p, p])  # [Point(x=3, y=4), Point(x=3, y=4)]  列表里用 __repr__
```

> 经验：只写一个时，优先写 `__repr__`——因为没定义 `__str__` 时，`str()` 会**回退**到 `__repr__`。

## 3. 魔术方法的共同特征

1. **名字固定**：前后双下划线，不能乱改。
2. **你实现，Python 调用**：几乎从不手动写 `obj.__str__()`。
3. **协议驱动**：什么场景触发什么方法，是语言约定好的。

---

## 4. 对象生命周期全景

一个对象从创建到销毁：

```text
User('Tom')
   ↓
调用 __new__      分配内存、创建对象
   ↓
调用 __init__     初始化、填充数据
   ↓
使用对象：
   print(user)  -> __str__
   user()       -> __call__
   with user:   -> __enter__ / __exit__
   len(user)    -> __len__
   a + b        -> __add__
   ↓
引用计数归零
   ↓
调用 __del__      销毁对象
```

## 5. 后端开发必须掌握的魔术方法（优先级）

**第一梯队（必须熟）：**

| 方法 | 用途 |
|------|------|
| `__init__` | 初始化对象 |
| `__str__` | 对象字符串表示（给人看） |
| `__repr__` | 开发调试显示 |
| `__call__` | 让对象函数化 |
| `__enter__` | 进入上下文 |
| `__exit__` | 退出上下文 |

**第二梯队（框架常用）：**

| 方法 | 用途 |
|------|------|
| `__getattr__` / `__setattr__` / `__delattr__` | 属性访问 |
| `__add__` 等 | 运算符重载（`a + b` → `a.__add__(b)`） |
| `__len__` | 容器协议（`len(obj)` → `obj.__len__()`） |

> 这些会在本主题后续小节逐一展开。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| 魔术方法 | 对象与 Python 的协议接口 |
| 自动调用 | 你实现，Python 按场景触发 |
| `__str__` / `__repr__` | 给人看 / 给开发者看 |
| 生命周期 | new → init → 使用 → 销毁 |

**核心认知**：掌握魔术方法 = 掌握 Python 对象如何与语言「协作」。后续的 `__new__`、`__call__`、`__enter__` 都是同一思想在不同场景的体现。
