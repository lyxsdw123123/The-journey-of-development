# 5. 属性访问协议

> 配套可运行脚本：`5. 属性访问协议.py`

## 0. 一句话结论

**访问对象的属性也是「协议」：`user.name` 实际上会触发 `user.__getattribute__("name")`。通过重写 `__getattr__` / `__setattr__` / `__getattribute__` 等，可以拦截和定制属性访问。**

---

## 1. 四个属性访问钩子

| 方法 | 触发时机 |
|------|----------|
| `__getattribute__` | **每次**访问属性都调用（最底层，先执行） |
| `__getattr__` | 属性**找不到**时才调用（兜底） |
| `__setattr__` | **每次**设置属性都调用 |
| `__delattr__` | 删除属性时调用 |

---

## 2. `__getattr__`：找不到时的兜底

```python
class LazyUser:
    def __init__(self, name):
        self.name = name
    def __getattr__(self, item):
        return f"默认_{item}"   # 属性不存在时返回默认值

u = LazyUser("Tom")
print(u.name)   # Tom      （存在，不触发）
print(u.age)    # 默认_age  （不存在，触发 __getattr__）
```

典型用途：**懒加载**、动态属性、代理对象（访问不存在的属性时按需计算）。

---

## 3. `__setattr__`：每次赋值都调用

```python
class Logged:
    def __setattr__(self, key, value):
        print(f"设置 {key} = {value}")
        super().__setattr__(key, value)   # 关键：真正写入

obj = Logged()
obj.age = 18   # 触发 __setattr__，打印 "设置 age = 18"
```

> **坑**：`__setattr__` 里必须用 `super().__setattr__(key, value)` 真正写入；如果写 `self.key = value`，会无限递归调用自己。

---

## 4. `__getattribute__`：每次访问都调用（最底层）

```python
class Traced:
    def __init__(self, name):
        super().__setattr__("name", name)
    def __getattribute__(self, item):
        print(f"访问 {item}")
        return super().__getattribute__(item)   # 关键：真正取值

t = Traced("Tom")
print(t.name)   # 打印 "访问 name"，返回 Tom
```

> **坑**：同样必须用 `super().__getattribute__(item)` 真正取值，否则无限递归。

---

## 5. `__getattr__` 与 `__getattribute__` 的区别（重点）

调用顺序：

```text
user.name
   ↓
1. __getattribute__("name")   # 每次访问都先调用
   ↓ 若抛 AttributeError（属性不存在）
2. __getattr__("name")        # 兜底
```

| 方法 | 触发频率 | 用途 |
|------|----------|------|
| `__getattribute__` | 每次访问 | 监控/拦截所有属性访问 |
| `__getattr__` | 仅属性缺失 | 懒加载、默认值、动态属性 |

> 实战记忆：`getattribute` 是「全拦截」（更底层、更危险），`getattr` 是「兜底」（更安全、更常用）。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| `__getattribute__` | 每次访问都触发，最底层 |
| `__getattr__` | 属性缺失才触发，兜底 |
| `__setattr__` | 每次赋值都触发 |
| `__delattr__` | 删除属性时触发 |
| 防递归 | 用 `super().__xxx__` 真正读写 |

**核心认知**：属性访问是「协议」，框架（ORM、序列化、代理）靠重写这些钩子实现拦截、懒加载、校验。记住：全拦截用 `__getattribute__`，兜底用 `__getattr__`。
