# 3. `__call__` 让对象可调用

> 配套可运行脚本：`3. __call__ 让对象可调用.py`

## 0. 一句话结论

**实现 `__call__` 之后，对象就能像函数一样被调用——`obj(x)` 等价于 `obj.__call__(x)`。这是装饰器、中间件、可调用对象的核心机制。**

---

## 1. 从「函数调用」到「对象调用」

函数能调用：

```python
def hello():
    print("hello")
hello()
```

对象也能调用（只要实现 `__call__`）：

```python
class AI:
    def __call__(self, text):
        print("AI 处理:", text)

model = AI()
model("你好")   # AI 处理: 你好
```

为什么？

```text
model("你好")
    ↓
model.__call__("你好")
```

---

## 2. 判断可调用：`callable()`

```python
def f():
    pass

class C:
    def __call__(self):
        pass

c = C()

print(callable(f))     # True  函数
print(callable(c))     # True  有 __call__ 的对象
print(callable("abc")) # False 字符串
```

判断依据：**有没有 `__call__` 方法**。

---

## 3. 可调用对象的优势：记住状态

普通函数每次调用都「失忆」，而带 `__call__` 的对象能保存内部状态：

```python
class Counter:
    def __init__(self):
        self.count = 0
    def __call__(self):
        self.count += 1
        return self.count

c = Counter()
print(c())   # 1
print(c())   # 2
print(c())   # 3
```

这就是「可调用对象」比纯函数灵活的地方——它既是「函数」，又是「对象」，能携带数据。

---

## 4. 实战：用 `__call__` 实现装饰器

很多装饰器本质就是一个带 `__call__` 的类：

```python
class Logger:
    def __call__(self, func):
        def wrapper():
            print("执行前")
            func()
            print("执行后")
        return wrapper

@Logger()
def hello():
    print("hello")

hello()
```

输出：

```text
执行前
hello
执行后
```

拆解 `@Logger()`：

```text
@Logger()
def hello():
    ...
```

等价于：

```python
hello = Logger()(hello)
```

```text
1. Logger()          创建装饰器对象
2. Logger()(hello)   调用它的 __call__，传入 hello
3. __call__ 返回 wrapper
4. hello 被替换成 wrapper
```

所以之后 `hello()` 实际执行的是 `wrapper()`。

## 6. 小结

| 概念 | 一句话 |
|------|--------|
| `__call__` | 让对象像函数一样调用 |
| `obj(x)` | 等价于 `obj.__call__(x)` |
| `callable()` | 判断对象是否可调用 |
| 可调用对象 | 能携带状态，比函数灵活 |
| 装饰器 | `@Logger()` 本质是调用 `__call__` |

**核心认知**：`__call__` 把「对象」和「函数」的界限打通——对象也能被调用，且能记住状态，这让装饰器、回调、中间件等模式变得优雅。
