# 6. GIL（Global Interpreter Lock，全局解释器锁）

> 配套可运行脚本：`6. GIL.py`

## 0. 一句话结论

**CPython 的 GIL 是一把全局锁：同一时刻只有一个线程能执行 Python 字节码。因此多线程在 CPU 密集任务上几乎不加速，但在 I/O 密集任务上依然有效。**

---

## 1. GIL 是什么

GIL = **Global Interpreter Lock（全局解释器锁）**，是 CPython 解释器里的一把互斥锁。

```text
线程1 ──┐
        ├── GIL（同一时刻只放行一个）── Python 字节码
线程2 ──┘
```

它保证：**同一时间，一个解释器进程里只有一个线程在执行 Python 字节码。**

> 为什么要有 GIL？因为 CPython 的内存管理（引用计数等）不是线程安全的，GIL 用「一锁打天下」的简单方式保证了安全。代价是牺牲了多线程的并行度。

---

## 2. 常见误解

很多人以为：

```text
两个线程 = 速度 ×2
```

实际是：

```text
线程1 执行 bytecode
   ↓  释放 GIL
线程2 执行 bytecode
   ↓  释放 GIL
线程1 又执行 ...
```

```text
CPU
线程1 ──┐
        ├── GIL
线程2 ──┘  （同一时刻只有一个在跑）
```

**两个线程是「轮流」执行，不是「并行」执行。**

---

## 3. CPU 密集：多线程几乎不加速

CPU 密集任务（大量纯计算，不碰 I/O）：

```python
def cpu_task(n):
    s = 0
    for i in range(n):
        s += i
    return s
```

单线程串行 vs 双线程「并行」——实测耗时几乎一样，甚至双线程因切换开销而更慢。

**原因**：全程都在抢 GIL，同一时刻只有一个线程在算，多线程只增加了锁竞争和上下文切换的开销。

**CPU 密集场景**（机器学习计算：矩阵计算、图像处理、大量循环）多线程效果差。

---

## 4. I/O 密集：多线程有效

I/O 密集任务（等待数据库、等待网络、等待文件）：

```python
import time
def io_task(name):
    time.sleep(1)   # 等待 I/O 期间会释放 GIL
```

两个线程同时做：耗时约 1 秒（串行要 2 秒）。

**原因**：线程在等待 I/O（`sleep`/网络/磁盘/数据库）时会**主动释放 GIL**，让别的线程能跑。于是多个线程能「同时等」，实现并发。

**I/O 密集场景**（Web 服务、爬虫等）多线程有效。

---

## 5. GIL 的切换机制

GIL 不是一直霸占，而是每隔一段时间（`sys.getswitchinterval()`，默认约 5ms）主动释放一次，让其他线程有机会拿锁：

```python
import sys
print(sys.getswitchinterval())   # 0.005（秒）
```

所以纯计算多线程「看起来也在跑」，只是轮流跑、不并行。

---

## 6. 正确解法

| 场景 | 推荐方案 |
|------|----------|
| CPU 密集 | `multiprocessing`（多进程，各进程有独立 GIL） |
| CPU 密集 | C 扩展 / Cython / Numba（把重活搬出 Python 层） |
| CPU 密集 | NumPy 等库（底层 C 实现，运算时释放 GIL） |
| CPU 密集 | CUDA（GPU 并行） |
| I/O 密集 | 多线程 `threading`（简单有效） |
| I/O 密集 | `asyncio`（单线程异步并发，现代推荐，适合大量连接） |

> 补充：Python 3.13 提供了实验性的 **free-threaded 版本**（可关闭 GIL），但当前生产主流仍是带 GIL 的 CPython。

## 8. 小结

| 概念 | 一句话 |
|------|--------|
| GIL | 同一时刻只允许一个线程执行字节码 |
| CPU 密集 | 多线程无效，用多进程/C 扩展/NumPy |
| I/O 密集 | 多线程有效（I/O 时释放 GIL） |
| asyncio | 单线程异步并发，绕开 GIL 争抢 |

**核心认知**：GIL 让 CPython 多线程「并发不并行」——I/O 密集用线程/asyncio，CPU 密集上多进程或 C 扩展。
