# 4. Depends 依赖注入

> 配套可运行脚本：`4. Depends 依赖注入.py`

## 0. 一句话结论

**`Depends(get_db)` 表面上只是「调用一下 get_db」，源码层面是声明依赖关系——`Dependant` + `solve_dependencies()` 解析依赖图，把结果注入 endpoint。**

---

## 1. Depends 背后的机制

```text
Depends()
   ↓
Dependant（依赖对象）
   ↓
依赖关系解析
   ↓
solve_dependencies()
   ↓
执行依赖
   ↓
得到结果
   ↓
注入 endpoint
```

---

## 2. 嵌套依赖

```python
def get_db():
    return {"db": "连接"}

def get_current_user(db=Depends(get_db)):
    return {"user": "Tom", **db}

@app.get("/users")
async def get_users(user=Depends(get_current_user)):
    return user
```

依赖图：

```text
Request
   │
   ↓
Route（/users）
   │
   ↓
Dependency Graph
   ├── get_current_user()
   │      └── get_db()
   ↓
Endpoint（get_users）
```

`solve_dependencies()` 从最底层 `get_db` 往上解析，结果层层注入。

---

## 3. Depends 能做什么

| 能力 | 说明 |
|------|------|
| 复用逻辑 | 数据库连接、当前用户、权限校验 |
| 嵌套依赖 | 依赖还能依赖别的依赖 |
| 缓存 | 同一请求内，同一依赖只执行一次 |
| 覆盖 | 测试时 `app.dependency_overrides` 替换 |

## 5. 小结

| 概念 | 一句话 |
|------|--------|
| Depends | 声明依赖关系 |
| Dependant | 依赖对象 |
| solve_dependencies | 解析依赖图 |
| 嵌套 | 依赖还能依赖依赖 |

**核心认知**：依赖注入是 FastAPI 的灵魂——它把「谁来提供参数」从 endpoint 里解耦出去，让数据库连接、认证、权限这些「横切关注点」可复用、可测试。
