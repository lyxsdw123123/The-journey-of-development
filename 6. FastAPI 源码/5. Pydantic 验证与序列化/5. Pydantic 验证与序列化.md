# 5. Pydantic 验证与序列化

> 配套可运行脚本：`5. Pydantic 验证与序列化.py`

## 0. 一句话结论

**Pydantic 负责请求的「解析 + 校验」和响应的「序列化」。三个关键词：Model（定义结构）、Validation（校验转换）、Serialization（转 dict/JSON）。**

---

## 1. Model

```python
class User(BaseModel):
    name: str
    age: int
```

字段和类型一目了然。

---

## 2. Validation

```python
User(name="Tom", age="18")   # 字符串 "18" 自动转成 int 18
User(name="Tom", age="abc")  # ValidationError
```

Pydantic 会进行**数据处理和校验**：能转换的转换，不能转换的报错。

---

## 3. Serialization

```python
user.model_dump()        # -> {"name": "Tom", "age": 18}  dict
user.model_dump_json()   # -> '{"name":"Tom","age":18}'  JSON 字符串
```

理解：`Python 对象 → dict → JSON`。

---

## 4. 完整数据流

```text
请求进来：
HTTP JSON -> Python 数据 -> Pydantic Model -> Validation -> Python 对象

响应出去：
Python 对象 -> Pydantic -> Serialization -> JSON -> HTTP Response
```

---

## 6. 小结

| 概念 | 一句话 |
|------|--------|
| Model | BaseModel + 类型注解 |
| Validation | 自动转换 + 校验 |
| Serialization | 转 dict / JSON |

**核心认知**：FastAPI 里 `user: User` 参数和 `response_model=User` 背后，都是 pydantic 在做「JSON ↔ Python 对象」的双向转换。它是 FastAPI 自动解析、验证、生成文档的基础。
