# The Journey of Development（开发之旅）

> 一名开发者的成长笔记：用 AI 辅助系统化学习开发知识，把每个知识点沉淀成「可运行示例 + 讲解文档」。

## AI 时代怎么学开发

AI 时代，学习方式变了——你不必再对着文档死记硬背，而应该：

1. **以「理解运行机制」为目标，而不是「会调用」**：让 AI 帮你把抽象概念拆成可运行的代码，亲手跑一遍、解剖一遍。
2. **追问「为什么」，而不是只拿答案**：每一层原理（词法分析 → 语法分析 → 编译 → 执行）都要能说清楚输入与输出。
3. **把知识沉淀成仓库，而不是聊天记录**：每学完一个知识点，产出「可运行 demo + 讲解文档」，长期积累、可回看、可分享。
4. **让 AI 成为你的陪练与审核员**：你动手写，AI 帮你验证、纠错、出题。

核心心法：**AI 负责加速「理解」，你负责把理解变成「作品」——这个仓库就是你的作品集。**

## 如何开始

每个知识点文件夹里都有：

- 一个 `.py` 脚本：直接 `python xxx.py` 就能跑，边跑边看每一层原理。
- 一个 `.md` 文档：系统讲解原理 + 动手清单 + 小结。

建议顺序：先读 `.md` 了解全貌，再跑 `.py` 亲手验证，最后按文档末尾的「挑战题」自己动手。

## 关于项目 Skill

本仓库自带一个项目级 Skill（`.agents/skills/dev-learning-notes`），它封装了「组织学习笔记」的目录与文件规范。在后续会话中，AI 会自动遵循这套规范来帮你整理新知识，保证结构统一、可增量扩展。
