# 3. 迭代器（Iterator）

> 配套可运行脚本：`3. 迭代器.py`

## 0. 一句话结论

**`for` 循环背后是「迭代器协议」：`iter(data)` 得到迭代器，再不断 `next(iterator)` 取下一个，取完抛 `StopIteration`。生成器其实就是一种迭代器。**

---

## 1. `iter()` 与 `next()`

```python
nums = [1, 2, 3]
it = iter(nums)     # 得到迭代器

print(next(it))     # 1
print(next(it))     # 2
print(next(it))     # 3
# next(it)          # 抛 StopIteration
```

---

## 2. `for` 循环的本质

`for item in data:` 背后等价于：

```python
it = iter(nums)
while True:
    try:
        item = next(it)
    except StopIteration:
        break
    # 处理 item
```

```text
for
  ↓
iterator
  ↓
next()
```

---

## 3. 可迭代对象 vs 迭代器

| 概念 | 判断 | 说明 |
|------|------|------|
| 可迭代对象（Iterable） | 有 `__iter__` | 能被 `iter()` 处理，如 list、str、dict |
| 迭代器（Iterator） | 有 `__next__` | 能不断 `next()`，取完抛 `StopIteration` |

- 列表是**可迭代对象**，但不是迭代器（不能直接 `next(list)`）。
- `iter(list)` 返回的才是**迭代器**。

---

## 4. 自己实现迭代器

```python
class CountDown:
    def __init__(self, start):
        self.current = start
    def __iter__(self):
        return self            # 迭代器返回自己
    def __next__(self):
        if self.current < 0:
            raise StopIteration  # 取完，停止
        value = self.current
        self.current -= 1
        return value

for x in CountDown(3):
    print(x)   # 3 2 1 0
```

实现迭代器协议：`__iter__` + `__next__`。

---

## 5. 生成器是迭代器

生成器自动实现了迭代器协议：

```python
def gen():
    yield 1
    yield 2

g = gen()
print(hasattr(g, "__iter__"))   # True
print(hasattr(g, "__next__"))   # True
print(next(g))                  # 1
```

所以**生成器就是一种迭代器**——用 `yield` 就能自动获得迭代器能力，而不用手写 `__next__`。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| 迭代器协议 | `iter()` + `next()` + `StopIteration` |
| 可迭代对象 | 能被 `iter()` 处理 |
| 迭代器 | 能不断 `next()` |
| 生成器 | 一种自动实现的迭代器 |

**核心认知**：`for` 循环不是魔法，而是「迭代器协议」的语法糖。理解 `iter`/`next`/`StopIteration`，你就能自定义任何可遍历的对象。
