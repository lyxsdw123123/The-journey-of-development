# 1. 装饰器（Decorator）

> 配套可运行脚本：`1. 装饰器.py`

## 0. 一句话结论

**装饰器就是在「不修改原函数代码」的前提下，给函数增加额外功能。`@log` 写在函数上，等价于 `hello = log(hello)`。**

---

## 1. 本质

FastAPI 里的：

```python
@app.get("/users")
def get_users():
    pass
```

看起来像 `@app.get("/users")`，实际上等价于：

```python
get_users = app.get("/users")(get_users)
```

```text
执行 app.get("/users")  -> 返回一个装饰器（handler）
再把 get_users 传进去     -> handler(get_users)
```

---

## 2. 手写一个简单装饰器

```python
def log(func):
    def wrapper():
        print("开始执行")
        func()
        print("执行结束")
    return wrapper

@log
def hello():
    print("hello")

hello()
```

输出：

```text
开始执行
hello
执行结束
```

等价关系：

```python
@log
def hello():
    ...

# 等价于
hello = log(hello)
```

`log` 接收原函数，返回包装后的 `wrapper`；之后调用 `hello()` 实际执行的是 `wrapper()`。

---

## 3. 支持参数与返回值

装饰器通常要透传参数、保留元信息：

```python
import functools

def log(func):
    @functools.wraps(func)          # 保留原函数的名字、文档等元信息
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        result = func(*args, **kwargs)   # 透传参数
        print(f"返回 {result}")
        return result                    # 透传返回值
    return wrapper

@log
def add(a, b):
    return a + b

add(1, 2)
```

> `functools.wraps(func)` 很重要：它让 `wrapper` 看起来像原函数（名字、文档字符串等），否则调试时函数名会变成 `wrapper`。

## 4. FastAPI 的真实过程

```python
@app.get("/users")
def get_users():
    return {"name": "Tom"}
```

FastAPI 实际做了：

```python
handler = app.get("/users")   # 返回一个装饰器
get_users = handler(get_users)
```

于是 FastAPI 内部保存了一张**路由表**：

```text
GET /users
    ↓
get_users 函数
```

当浏览器访问 `http://localhost:8000/users`：

```text
请求 -> 匹配路由 -> 执行 get_users() -> 返回 JSON
```

---

## 5. 后端哪里大量使用装饰器

| 场景 | 示例 |
|------|------|
| 路由注册 | `@app.get("/users")` |
| 权限认证 | `@login_required` |
| 日志 | `@log` |
| 计时 | `@timer`（自动统计「模型训练耗时 30 秒」） |

```python
@login_required
def user_info():
    pass
# 请求 -> 权限检查 -> 原函数
```

共同点：**都是「不改原函数，包装一层通用逻辑」**。

## 7. 小结

| 概念 | 一句话 |
|------|--------|
| 装饰器 | 不改原函数，加功能 |
| `@log` | 等价于 `hello = log(hello)` |
| `functools.wraps` | 保留原函数元信息 |
| FastAPI `@app.get` | 本质是装饰器，注册路由 |

**核心认知**：装饰器是「高阶函数」——函数作为参数传入、返回新函数。它是 FastAPI 路由、认证、日志、计时等一切「横切关注点」的基石。
